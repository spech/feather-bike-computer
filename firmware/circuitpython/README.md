# CircuitPython firmware

First firmware implementation for the FeatherS3[D]. See the [roadmap](../../docs/roadmap.md) for planned work.

- `core/` — hardware-independent logic: ride data, statistics, and state.
- `hw/` — drivers and setup for the display, GPS, barometric sensor, ANO encoder, and power.
- `ui/` — screens, layouts, and navigation for the e-paper display.

Hardware connections are described in [docs/wiring.md](../../docs/wiring.md).
